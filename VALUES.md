# Values — what estate upholds beyond its laws

Each row names a value, its requirement in one sentence, the mechanism that holds it, and the check
that shows it holds. A `Where` names an existing test, CI job, verb, analyzer rule, hook or file,
and says what the check asserts when its name does not; a test that holds a row declares
`[Trait("Value", "<row>")]`, and `LAWS.md` lists each row's tests. Or it names the test a work package
adds, marked `not held yet: WP <n>.<m>` until that milestone's exits are all run, or
`not held yet: the cutover tools` (`emit`, `decide`, `move`) until M8 starts; or says *prose only*,
which marks a known weakness. People judge three things no test can:
whether a name is the domain's, whether a rationale is substantive, and whether a pull request
description reads well to the dev lead. Where v2 stated each value, and whether it had a mechanism
there, is in `V3_INSTRUCTION_ARCHITECTURE.md` §4.
