# temporal-new

A new system-versioned table, created with its period columns, its history table and SYSTEM_VERSIONING on. The
history table, declared or generated by DacFx, is part of the table's entry. No existing row is read or written.

Measured on DacFx 170.5.96: a system-versioned table with infinite retention holds RetentionUnit -1.

```text
recognize:
  match: created Table RetentionUnit=-1
  ships: one release, in place
```
