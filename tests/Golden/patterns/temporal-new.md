# temporal-new

A new system-versioned table, created with its period columns and SYSTEM_VERSIONING on, and the history table DacFx
generates for it when the change declares none. No existing row is read or written.

Measured on DacFx 170.5.96: a system-versioned table with infinite retention holds RetentionUnit -1, and a history
table DacFx generates holds IsAutoGeneratedHistoryTable true.

```text
recognize:
  match: created Table RetentionUnit=-1
  match: created Table IsAutoGeneratedHistoryTable=true
  ships: one release, in place
```
